Подпись на сайте будет в формате: **CLIENT, TITLE, PRODUCTION**
(пример из референса: `JORJA SMITH, FALLING OR FLYING, STINK FILMS`).

## Ещё пара вопросов (общие)

1. **Твоя роль на каждом проекте** — одна на всех (costume / set design / props / production
   design) или разная по проектам? Если разная — напиши коротко по каждому. _(Можно показывать
   роль в подписи, напр. «… — COSTUME DESIGN».)_
2. **Агентство** — у тебя есть агент/агентство, которое тебя представляет? Если да — название
   + контактный email для строки AGENCY в разделе Contact. Если нет — уберём эту строку.
3. **Список клиентов для бегущей строки** — кроме этих 10, с кем ещё работала (бренды, артисты,
   продакшены)? Дай полный список, через запятую — это «социальное доказательство» в шапке.
4. **Другие категории** — есть готовые работы для разделов **Music Video / Film / Theater /
   Editorial / Art**? Если да — пришли папки так же, как Commercials, и наполним.
