# 2026-06-18 — Курированные превью из папок «Use this»

## 1. Задача
Дмитрий: заменить главные фото-превью работ на курированные кадры (он сложил их в папки `Use this` внутри каждой папки проекта в `~/Downloads/Commercials`), убрать лишние низкокачественные/дублирующиеся кадры. Применить **только к проектам без видео — пока**.

## 2. Как решал
Сначала свёл факты и нашёл расхождение с постановкой:
- Папки `Use this` реально существуют только у **4** проектов: Tommy Lotto, Delta, Lascana, Victorinox.
- Из них «без видео на сайте» — только Delta, и в её `Use this` лежит **видео** (`IMG_9474.MOV`), а не фото.
- У трёх остальных безвидеошных работ (`bolt-caromatherapy`, `bolt-whatever-you-do`, `tommy-cash-eurovisioon`) папок `Use this` нет вовсе.

Спросил Дмитрия двумя вопросами. Решения: (1) обработать **все 4** папки `Use this` (включая видео-работы — там меняем фото-превью на курированные), (2) старые низкокачественные кадры **удалить**, оставить только `Use this`.

Реализация:
1. Написал узкий скрипт [scripts/import-use-this.ts](../scripts/import-use-this.ts) — повторяет slugify/derivative-логику `import-media.ts`, но генерит деривативы только для 6 явных файлов и **дозаписывает** их в существующий `works.manifest.json` (полный импортер пересобрал бы лишнее из всех 17 папок Commercials и затёр бы манифест).
2. Переписал `final[]` в 4 `index.json` на курированные кадры; первый = превью. Превью выбирал по картинке: Lascana — портрет на скале; Victorinox — кадр с роботами; Tommy Lotto и Delta — по одному.
3. Удалил неиспользуемые деривативы из `public/works/<slug>/` (488 файлов), не трогая `process[]`.
4. Подчистил 62 осиротевшие записи в манифесте.
5. `next build` — зелёный, все 12 работ генерятся.

## 3. Решил ли — да.
Все 4 работы получили курированные превью, старое удалено, сборка проходит.

## 4. Эффективность / что лучше
- Узкий скрипт вместо полного импортера — правильный выбор: минимальный blast-radius, манифест других работ не тронут. Стоит держать `import-use-this.ts` как переиспользуемый паттерн для будущих партий `Use this`.
- Расхождение «папки есть в каждой» vs реальность (только 4) поймал до правок — сэкономило переделку.
- Не идеально: для Lascana/Victorinox порядок 2 кадров выбрал на глаз — Дмитрий может переставить (первый в `final[]` = превью).

## 5. Как было / как стало
- **Было:** превью = низкокачественные стопкадры (`low-quality-screenshot-*`, HEIC-постеры). Delta — 24 кадра, Lascana/Victorinox — 13–19 низкокачественных.
- **Стало:** Tommy Lotto — 1 кадр, Lascana — 2, Victorinox — 2, Delta — 1 (постер из `Use this`-видео). Качество превью заметно выше.
